# XcpCam

一个 Dalamud 插件：在 GPose 里把镜头（例如 Brio 的各个相机）作为节点摆在一条**按帧计时的相机时间轴**上，生成平滑运镜，可以导出为 XAT `.xcp` 相机文件，也可以直接联动 Brio 的灵动时间轴（Vivacity）。插件会在游戏画面里显示运镜路径和每个镜头，选中的镜头可以直接用变换手柄拖动、旋转。

> 状态：预览版本。离线测试全部通过，游戏内验证仍在进行中。

## 用法

1. 进入 GPose，选中一个角色作为目标（运镜坐标相对于这个角色）。
2. 输入 `/xcpcam` 打开面板。
3. **相机时间轴**页：
   - 在 Brio 中摆好一个镜头，把播放头移到想要的帧，点 **在播放头抓取镜头**；也可以点 **追加到末尾**，自动排在最后一个镜头之后。
   - **从运镜生成关键帧**：把播放头移到已有运镜中的某一帧，点这个按钮，就会在这一帧插入一个镜头节点，位置、旋转、FoV 都取运镜在这一帧的值。之后可以单独拖动它，或用手柄调整，来修改这一段运镜。
   - 在时间轴上**拖动 ◆ 节点**可以改变镜头所在的帧，精确到帧。点击空白处移动播放头；滚轮平移，Ctrl+滚轮缩放，中键拖动。
   - 时间轴的帧率默认**跟随 Brio 灵动时间轴**。帧率改变时，节点会自动换算，保持原来的秒数不变。
   - 选中节点后，可以在下方面板精确修改：所在帧、停留帧数、经过方式（自动 / 停顿 / 匀速），以及相对位置、旋转、FoV。修改都支持撤销 / 重做。
4. **游戏内显示与编辑**（同样在相机时间轴页，就在时间轴下方）：
   - 「游戏内显示」：在游戏画面中显示运镜路径和各个镜头的视锥。更多选项在页面底部的「显示选项」里。
   - 「变换手柄」：选中节点后，游戏画面中该镜头的位置会出现手柄，可以直接拖动来移动或旋转镜头。支持本地坐标 / 世界坐标，以及按步长吸附。
5. 选择运镜节奏：
   - **按时间平滑**（默认）：每个镜头在它所在的帧到达，经过镜头时速度连续，不会顿挫。
   - **整体匀速**：从第一个节点到最后一个节点匀速运动，只在首尾缓入缓出。
6. 预览：
   - 在时间轴上播放或拖动播放头，游戏画面中的绿色视锥会沿路径移动。
   - 也可以勾选时间轴下方的 **预览镜头**，让 Brio 当前的自由相机直接显示这一帧的画面。
7. 输出方式（任选其一）：
   - **导出 .xcp**：在 Brio 相机编辑器中选择 XAT Camera，加载文件后播放。
   - **Brio 联动**页，方式 1「联动 XAT」：Brio 时间轴播放到第一个节点所在的帧时，自动从头播放这段运镜。
   - **Brio 联动**页，方式 2「烘焙」：按节点所在的帧写进 Brio 自由相机的时间轴相机轨道，之后拖动、暂停、循环都完全同步，也可以撤销。
   - 还可以让本插件的播放头**跟随**或**驱动** Brio 时间轴。

## 实现说明

- **抓取**：读取游戏当前正在渲染的相机 `SceneCamera.ViewMatrix`，也就是 Brio 写入的那个矩阵，因此 Brio 的自由相机和普通相机都能抓取。
- **坐标换算**：完全按照 Brio `CutsceneManager.UpdateCamera()` 的公式反推，每次抓取后都会用播放公式重建视图矩阵做自检。
- **路径形状**：向心 Catmull-Rom 曲线穿过所有关键帧，并建立弧长表，可以按"走过的距离"取曲线上的点。
- **节奏**：
  - 按时间平滑：所有关键帧共用一条全局的单调 Hermite 曲线，把时间映射成走过的距离（Fritsch–Butland 切线），所以速度在关键帧处连续，镜头也不会倒退。
  - 整体匀速：中段速度恒定，首尾用 smoothstep 速度曲线缓入缓出，位置、速度、加速度都连续。
- **旋转**：非均匀节点的 SQUAD 四元数样条，角速度在关键帧处连续。FoV 用 Hermite 插值。
- **Brio 联动**：Brio 没有提供时间轴或相机的 IPC，所以通过反射访问 Brio 内部。所有用到的成员名都集中在 `Brio/BrioBridge.cs`，找不到成员时只禁用对应功能，不会崩溃。已在 Brio 0.8.0.12 上核对过。
- **文件格式**：`"XCP1"` + uint32 帧数 + 每帧（pos xyz、rot xyzw、fov），小端序，30fps。Brio 的读取代码会少读最后一帧，所以文件头写入 N+1，并在末尾重复写一次最后一帧。

## 构建

需要 .NET 10 SDK 和 XIVLauncher / Dalamud（API 15）。

```
dotnet build -c Release
```

如果 Dalamud 不在默认位置（例如国服），请先设置 `DALAMUD_HOME`：

```
set DALAMUD_HOME=%APPDATA%\XIVLauncherCN\addon\Hooks\dev\
```

将 `bin/Release/XcpCam.dll` 添加到 Dalamud 设置 → 实验性功能 → Dev Plugin Locations。

离线测试（不需要游戏）：

```
cd Tests
dotnet run -c Release
```
